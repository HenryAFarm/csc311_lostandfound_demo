# csc311_lostandfound_demo

#Purpose
Allows you to report a lost item if you have found one!
Here in this site you can sign in/register yourself to report an item you found.
So that the next person can see if one of these items is their!

You can also login in, with the username and password you had given when you first signed up for this application.
When registered, information is saved through the H2 database. Making sure that when you login in again, it remembers you.

#To use
Make sure that you are running it so that you can go onto the
localhost:8080 for this application to be seen.

#Implementation 
Using SpringBoot 4.1.1 as the framework for this application. 

#Requirements
JDK 21 or above!
